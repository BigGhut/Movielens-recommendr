# Python Test Harness Skill

Enforces strong test coverage and test design.

## Test Rules
1. **Framework**: Use `pytest` for all tests.
2. **Fixtures**: Use pytest fixtures to manage reusable setup/teardown code.
3. **Mocking**: Mock external dependencies (APIs, databases, disk access) using `unittest.mock` or pytest plugins.
4. **Assertions**: Test both happy paths and edge cases (including exceptions using `pytest.raises`).
